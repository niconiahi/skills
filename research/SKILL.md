# Research

A background agent does the research so the work in the foreground continues while it reads.

It investigates the question against primary sources, official docs, source code, specs and first-party APIs rather than a secondary write-up of them, following every claim back to the source that owns it.

It writes the findings to a single Markdown file citing each claim's source, saves it under [docs/research/](../../../docs/research/), where the repo keeps such notes, and adds it to that directory's [README.md](../../../docs/research/README.md).
